Yes, the overall process is the same on Windows, but the commands are slightly different.
Here’s the proper Windows version step-by-step for your CRUD API project using Node.js, Express, and MongoDB.

---

# STEP 1: Install Requirements on Windows

## 1. Install Node.js

Download from:

[Node.js Official Website](https://nodejs.org?utm_source=chatgpt.com)

* Install the LTS version
* Keep all settings default
* After installation, open Command Prompt and check:

```bash
node -v
npm -v
```

---

## 2. Install MongoDB

Download MongoDB Community Server:

[MongoDB Community Server](https://www.mongodb.com/try/download/community?utm_source=chatgpt.com)

During installation:

* Select **Complete**
* Enable **Install MongoDB Compass**
* Finish installation

Check MongoDB:

```bash
mongod --version
```

---

# STEP 2: Create Project

Open Command Prompt:

```bash
mkdir crud-api
cd crud-api
```

Initialize project:

```bash
npm init -y
```

Install packages:

```bash
npm install express mongoose body-parser
```

---

# STEP 3: Create server.js

Inside `crud-api` folder:

```bash
notepad server.js
```

Paste this code:

```javascript
const express = require("express");
const mongoose = require("mongoose");

const app = express();
app.use(express.json());

// Connect MongoDB
mongoose.connect("mongodb://127.0.0.1:27017/testdb");

// Schema
const UserSchema = new mongoose.Schema({
    name: String,
    email: String
});

const User = mongoose.model("User", UserSchema);


// 1. CREATE (POST)
app.post("/addUser", async (req, res) => {
    const user = new User(req.body);
    await user.save();
    res.send("User Added");
});


// 2. READ (GET)
app.get("/getUsers", async (req, res) => {
    const users = await User.find();
    res.json(users);
});


// 3. UPDATE (PUT)
app.put("/updateUser/:id", async (req, res) => {
    await User.findByIdAndUpdate(req.params.id, req.body);
    res.send("User Updated");
});


// 4. DELETE (DELETE)
app.delete("/deleteUser/:id", async (req, res) => {
    await User.findByIdAndDelete(req.params.id);
    res.send("User Deleted");
});


// Start server
app.listen(3000, () => {
    console.log("Server running on port 3000");
});
```

Save:

* Press `CTRL + S`
* Close Notepad

---

# STEP 4: Start MongoDB

Open another Command Prompt:

```bash
mongod
```

Keep this window open.

---

# STEP 5: Run Server

In project folder:

```bash
node server.js
```

Output:

```bash
Server running on port 3000
```

# Important Difference Between Ubuntu & Windows

| Ubuntu/Linux          | Windows                     |
| --------------------- | --------------------------- |
| sudo apt install      | Download .exe installer     |
| Terminal              | Command Prompt / PowerShell |
| Linux package manager | Manual installation         |
| mongod service        | MongoDB Windows Service     |

---

# Optional Better Command

Instead of:

```bash
node server.js
```

Install nodemon:

```bash
npm install -g nodemon
```

Run:

```bash
nodemon server.js
```

This auto-restarts server whenever you save changes.
